# 🎬 ÉTAPE PAR ÉTAPE (30 MIN)

## 📍 ÉTAPE 1 : Créer un compte GitHub (5 min)

### C'est quoi GitHub ?
C'est comme **Dropbox** ou **Google Drive**, mais pour du code. C'est là où votre téléphone va se "construire" automatiquement.

### Comment faire :

1. **Ouvrez votre navigateur** (Chrome, Firefox, Safari, Edge...)

2. **Allez sur** : https://github.com/signup

3. **Remplissez le formulaire** :
   - Votre email
   - Un mot de passe
   - Un nom d'utilisateur (exemple : `JohnPhone`)
   
4. **Cliquez sur** "Create account"

5. **Vérifiez votre email** et cliquez sur le lien

✅ **TERMINÉ !** Vous avez un compte GitHub.

---

## 📍 ÉTAPE 2 : Créer votre "dépôt" (5 min)

### C'est quoi un dépôt ?
C'est comme un **dossier en ligne** où vous allez mettre vos fichiers.

### Comment faire :

1. **Sur GitHub**, cliquez sur le **+** en haut à droite

2. **Cliquez sur** "New repository"

3. **Remplissez** :
   - **Repository name** : `lineageos-j3-2017`
   - **Description** : `LineageOS 23 pour mon J3 2017`
   - **✅ Cochez** "Public" (c'est OBLIGATOIRE pour que ce soit gratuit)
   - **✅ Cochez** "Add a README file"

4. **Cliquez** sur le bouton vert "Create repository"

✅ **TERMINÉ !** Vous avez créé votre dépôt.

---

## 📍 ÉTAPE 3 : Uploader les fichiers (10 min)

### Vous allez mettre TOUS les fichiers que je vous ai donnés sur GitHub.

### Comment faire :

1. **Sur votre dépôt GitHub**, cliquez sur **"Add file"** → **"Upload files"**

2. **Sur votre ordinateur**, ouvrez le dossier **`device-tree-j3y17lte`** que vous avez téléchargé

3. **Sélectionnez TOUS les fichiers et dossiers** :
   - Cliquez sur le premier fichier
   - Maintenez **Ctrl** (Windows/Linux) ou **Cmd** (Mac)
   - Cliquez sur le dernier fichier
   - Tous les fichiers sont maintenant sélectionnés (en bleu)

4. **Glissez-déposez** tous ces fichiers dans la fenêtre GitHub
   - Ou cliquez sur "choose your files" et sélectionnez tout

5. **Attendez** que la barre de chargement se remplisse (2-5 min)

6. **En bas de la page**, dans la case **"Commit changes"** :
   - Laissez le texte par défaut
   - Cliquez sur le bouton vert **"Commit changes"**

✅ **TERMINÉ !** Tous vos fichiers sont maintenant en ligne.

---

## 📍 ÉTAPE 4 : Activer la compilation automatique (5 min)

### Maintenant, vous allez demander à GitHub de "construire" votre téléphone automatiquement.

### Comment faire :

1. **Dans votre dépôt**, cliquez sur l'onglet **"Actions"** (en haut)

2. **Si vous voyez** un message "Workflows aren't being run..." :
   - Cliquez sur le bouton vert **"I understand my workflows, go ahead and enable them"**

3. **Vous devriez voir** : "There are no workflow runs yet"

✅ **TERMINÉ !** La compilation automatique est prête.

---

## 📍 ÉTAPE 5 : Lancer la compilation (2 min)

### C'est le moment magique ! GitHub va construire votre ROM LineageOS 23.

### Comment faire :

1. **Toujours dans "Actions"**, dans la barre de gauche, cliquez sur :
   **"Build LineageOS 23 - Galaxy J3 2017 Ultimate"**

2. **À droite**, cliquez sur le bouton gris **"Run workflow"**

3. **Une fenêtre s'ouvre** avec 3 choix :
   - **Device codename** : Laissez `j3y17lte`
   - **Build type** : Sélectionnez `userdebug`
   - **Optimization level** : Sélectionnez `balanced` (pour commencer)

4. **Cliquez** sur le bouton vert **"Run workflow"**

5. **Attendez 5 secondes**, puis **rafraîchissez la page** (F5 ou Ctrl+R)

6. **Vous devriez voir** une ligne jaune avec un cercle qui tourne ⚪
   - C'est bon ! La compilation a commencé !

✅ **TERMINÉ !** Votre ROM se construit automatiquement !

---

## ⏳ PATIENCE : Attendez 2-4 heures

### Pendant que ça compile :

- ☕ **Buvez un café**
- 🍕 **Mangez un truc**
- 📺 **Regardez Netflix**
- 🎮 **Jouez à un jeu**

### Comment vérifier où ça en est :

1. **Retournez sur** votre dépôt GitHub

2. **Cliquez sur** "Actions"

3. **Vous verrez** :
   - ⚪ **Cercle jaune qui tourne** = En cours (soyez patient)
   - ✅ **Coche verte** = TERMINÉ ! (passez à l'étape suivante)
   - ❌ **Croix rouge** = Erreur (regardez l'étape "Dépannage" à la fin)

---

## 📥 ÉTAPE 6 : Télécharger votre ROM (3 min)

### Quand vous voyez la ✅ **coche verte**, c'est prêt !

### Comment faire :

1. **Cliquez** sur la ligne avec la coche verte

2. **Descendez** tout en bas de la page

3. **Vous verrez** une section **"Artifacts"**

4. **Cliquez** sur le fichier ZIP (environ 600-800 MB)
   - Nom du style : `LineageOS-23-j3y17lte-20260215.zip`

5. **Le téléchargement commence** automatiquement

6. **Attendez** que le téléchargement se termine (5-15 min selon votre connexion)

✅ **TERMINÉ !** Vous avez votre ROM LineageOS 23 !

# ❓ QUESTIONS FRÉQUENTES

### Q : C'est vraiment gratuit ?
**R :** OUI ! GitHub Actions est 100% gratuit pour les dépôts publics.

### Q : Combien de fois je peux compiler ?
**R :** ILLIMITÉ ! Vous pouvez recommencer autant de fois que vous voulez.

### Q : Mon Mac M1 ne peut pas compiler ?
**R :** Ce n'est pas votre Mac qui compile, c'est GitHub sur internet ! Votre Mac sert juste à uploader les fichiers.

### Q : Ça va casser mon téléphone ?
**R :** Si vous suivez EXACTEMENT le guide d'installation, NON. Mais faites TOUJOURS un backup avant.

### Q : Je peux changer de profil (maximum, battery, etc.) ?
**R :** OUI ! Relancez juste le workflow (Étape 5) et choisissez un autre profil.
