## 📱 PARTIE 3 : PRÉPARATION DU TÉLÉPHONE (30 MIN)

### Backup :

## 🔧 PARTIE 4 : INSTALLATION (15 MIN)

### Transfert :
- [ ] J'ai connecté le téléphone à l'ordinateur
- [ ] J'ai copié le fichier ROM sur le téléphone
- [ ] Le fichier est dans "Download" ou à la racine

### TWRP :
- [ ] J'ai redémarré en Recovery (Vol+ + Home + Power)
- [ ] Je suis dans TWRP (écran bleu)

### Wipe :
- [ ] J'ai appuyé sur "Wipe"
- [ ] J'ai appuyé sur "Advanced Wipe"
- [ ] J'ai coché : Dalvik, Cache, System, Data
- [ ] Je N'AI PAS coché "Internal Storage"
- [ ] J'ai glissé pour wiper
- [ ] Le wipe est terminé

### Flash :
- [ ] J'ai appuyé sur "Install"
- [ ] J'ai trouvé le fichier lineage-23.0-*.zip
- [ ] J'ai appuyé dessus
- [ ] J'ai glissé pour flasher
- [ ] J'ai attendu 3-5 minutes
- [ ] Je vois "Successful" en vert
- [ ] J'ai appuyé sur "Reboot System"
